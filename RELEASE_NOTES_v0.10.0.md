# Cuty-SSH v0.10.0 — Session Icon Picker & Drag-to-Collapse Sidebar

## ✨ New in v0.10.0

### Session editor: icon picker
* The free-text « Icône » field is now a **dropdown grid of 38 icons** (servers, OS, databases, cloud, security, network, environments, colored dots). A **custom field** remains available for any other emoji.
* The icon shows up everywhere sessions are listed: sidebar, tabs, cockpit cards and the quick-switch palette.

### Sessions sidebar: drag it closed
* Dragging the sidebar's resize handle well past its minimum width now **hides the sidebar**, in the same spirit as the window dismissal gestures. Re-open it with the **Sessions** toolbar button.
